## 背景与问题

扩展选择类题型，新增"图片上传题"，让问卷填写者可以通过上传图片的方式进行回答。

---

## 目标

在问卷系统中新增"图片上传题"题型，支持：
- B端：题型搭建（配置标题、必填、显示设置、上传限制）
- C端：图片上传交互（选择、上传、删除、格式/大小校验）
- 数据分析端：已上传图片的缩略图展示和原图预览

---

## 范围

### 在范围内

**B端（题型搭建）：**
- 题型选择菜单新增"高级题型 - 图片上传"
- 题型添加：每份问卷可添加多个图片上传题
- 题目标题：默认【标题X】，支持修改
- 答题区：默认显示图片上传符号，提示"最多上传5张"
- 单题设置 - 基础配置：
  - 必填（默认勾选）
  - 显示类型（默认不勾选）
  - 显示序号（默认勾选）
  - 显示分割线（默认勾选，仅移动端）
  - 最大可上传图片数（下拉，1-10，默认5）
  - 单个文件大小限制 MB（输入框，1-100整数，默认100）

**C端（问卷填写）：**
- 必填项 `*` 标识
- 序号/标题/题型名称展示（与B端配置联动）
- 图片上传按钮和提示文案（"最多上传n张"）
- PC端：本地文件选择；移动端：相机/相册选择
- 多图上传；超过限制时提示并失败
- 格式限制：bmp、jpg、jpeg、png、tif、gif、heic
- 大小限制：超限提示并失败
- 上传中可取消；上传完成后可删除
- 达到上限后隐藏上传按钮
- 提交时必填校验：未上传则提示且阻止提交

**数据分析端：**
- 数据列表：缩略图，一行3个，鼠标移入放大
- 点击缩略图：弹窗原图，支持缩放和左右切换

### 不在范围内

- 分题统计：图片题不支持（统计无法从图片内容提取结构化数据）
- 视频上传
- 其他文件类型（PDF、文档等）

## 验收条件

### B端
- [ ] 题型菜单中可找到"高级题型 - 图片上传"，鼠标悬浮显示样例
- [ ] 可向问卷中添加多个图片上传题
- [ ] 题目标题默认"标题X"，点击可修改
- [ ] 单题设置面板中可配置：必填 / 显示类型 / 显示序号 / 显示分割线
- [ ] 最大可上传图片数：下拉选择 1-10，默认 5，修改后答题区提示同步更新
- [ ] 单个文件大小限制：输入框，默认 100，输入非法值后恢复默认值

### C端
- [ ] 根据B端配置正确展示：* 必填标识 / 序号 / 标题 / 题目类型 / 分割线
- [ ] 图片上传按钮点击：PC 打开文件选择，移动端打开相机/相册
- [ ] 超出最大上传数限制时，提示并上传失败
- [ ] 格式不支持时，提示上传失败
- [ ] 超过文件大小限制时，提示并上传失败
- [ ] 已上传图片右上角有删除按钮，上传中可取消，上传完成可删除
- [ ] 达到上限后不再显示上传按钮
- [ ] 必填且未上传时，点击提交：弹窗提示 + 定位到该题 + 题目下方显示错误提示

### 数据分析
- [ ] 每份回答中图片以缩略图展示，一行3个
- [ ] 鼠标移入缩略图时放大预览
- [ ] 点击缩略图弹窗展示原图，支持缩放，支持左右切换
- [ ] 分题统计中不出现图片上传题
