# 新增图片上传题

## 目标

扩展题型库，新增"图片上传题"，支持 B 端搭建配置、C 端图片上传交互、数据分析端图片展示。

## 范围

涉及模块：
- 前端：`web/src/materials/questions/widgets/` — 新增 imageUpload 题型物料
- 前端：`web/src/management/` — 题型菜单注册
- 前端：`web/src/render/` — C 端渲染和上传交互
- 后端：`server/src/modules/survey/template/` — 题型模板 JSON
- 后端：`server/src/modules/file/` — 文件上传接口（如已有可复用）
